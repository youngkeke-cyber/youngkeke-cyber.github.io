# 돌봄온길 (Dolbom-on-gil)

**가족돌봄 청소년·청년 복지 내비게이션** — 가족을 돌보느라 자신을 돌볼 시간이 없는
청소년(13~18세)·청년(19~34세)이 자신에게 맞는 복지 지원을 쉽게 찾고 신청까지 마칠 수 있도록
안내하는 정적 웹사이트입니다.

> IBC 19기 · 돌봄 2팀 — PROBLEM TREE → SOLUTION TREE 파일럿 서비스

🔗 **배포 주소:** https://dolbomongil.com/ (GitHub Pages, 커스텀 도메인)

## 세 가지 솔루션

1. **맞춤 큐레이션** — 대상(청소년/청년)·지역·돌봄 상황·소득·필요를 묻는 다섯 가지 질문으로
   전국 공통 제도와 우리 지역 혜택 중 해당 가능성이 높은 지원만 좁혀 보여줍니다.
2. **쉬운 언어 한 장 요약** — 각 제도를 「누가·얼마나·서류·어디서·언제」 카드로 압축하고,
   공고문의 어려운 용어에는 마우스 오버(모바일은 터치) 풀이와 별도 용어 사전을 제공합니다.
3. **신청 동행 로드맵** — 서류 준비부터 결과 확인까지 단계별 체크리스트를 제공하고,
   각 단계에서 필요한 정부 사이트(복지로·정부24·청년ON 등)로 바로 연결하며,
   진단 결과에 맞춰 동행 코디네이터 연결 안내까지 이어집니다.
   진행 체크 상태는 브라우저(localStorage)에 저장되어 다시 방문해도 유지됩니다.

## 프로젝트 구조

```
.
├── index.html            # 메인 페이지 (구조/콘텐츠)
├── 404.html              # 존재하지 않는 경로 안내
├── favicon.svg           # 파비콘
├── .nojekyll             # GitHub Pages Jekyll 처리 비활성화
└── assets/
    ├── css/styles.css    # 스타일
    └── js/app.js         # 진단·매칭·로드맵 로직 및 데이터
```

## 로컬에서 실행하기

별도 빌드 과정이 없는 순수 정적 사이트입니다. 저장소를 받은 뒤 아래 중 하나로 실행하세요.

```bash
# 파이썬 내장 서버
python3 -m http.server 8000
# 접속: http://localhost:8000
```

또는 `index.html`을 브라우저에서 직접 열어도 동작합니다.
